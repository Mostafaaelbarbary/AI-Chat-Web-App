# AI-Chat-Web-App

Full-stack AI chat application built with React and FastAPI, integrating OpenAI API for real-time conversational AI.

## Features
- Interactive chat UI (React)
- FastAPI backend
- OpenAI LLM integration
- REST API communication

## Tech Stack
- Frontend: React, Vite
- Backend: FastAPI, Python
- AI: OpenAI API

## Run Locally

### Backend
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload

### Frontend
cd frontend
npm install
npm run dev
